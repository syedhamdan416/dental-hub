# DentalHub Frontend

A standalone HTML, CSS and vanilla JavaScript learning-platform prototype. No build step is required.

## Run
1. Extract the ZIP.
2. Open `DentalHub_CaseLibrary/index.html` in a browser, or use VS Code Live Server.
3. Sign in with any valid-looking email address and any non-empty password. Authentication is a frontend demonstration only.

## Nine working workspace modules
1. **Dashboard** — live counts for completed lessons, completed cases and saved cases.
2. **My Learning** — three course paths with lesson completion tracking.
3. **Case Library** — searchable and filterable teaching cases, overview, patient brief, questions, hints, feedback, results and answer review.
4. **X-Ray Trainer** — interactive radiographic reasoning practice with feedback and a final score. This version uses written image scenarios rather than uploaded radiographs.
5. **AI Study Tools** — upload or paste plain text to produce a revision outline, key terms and expandable flashcards using local text-processing rules. No live AI service is connected in this standalone prototype.
6. **My Progress** — saved case attempts, scores, accuracy and review links.
7. **Bookmarks** — save and remove cases for later revision.
8. **Study Notes** — create, edit and delete personal notes.
9. **Daily Challenge** — daily five-question knowledge check with saved answers and explanations.

Settings and Log out remain under Preferences. The updated DentalHub logo has a transparent background, appears in the dashboard sidebar, and is clickable to return to the Dashboard. The login form keeps the centred logo; the left login panel uses only the DentalHub wordmark.

## Data and limitations
Learning completion, case attempts, bookmarks, notes, daily challenge answers and preferences are saved in browser local storage on the current device. Clearing browser storage removes this demo data. This prototype has no backend, real authentication, connected AI model, administrator role or clinical image diagnosis. Educational case material is illustrative and not clinical advice.
